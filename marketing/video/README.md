# Video

Use this folder for App Store preview videos, short-form ads, screen-record scripts, VO scripts, caption plans, and edit notes.

Each video brief should include:

- channel and format;
- duration target;
- hook;
- shot list;
- exact app screens or recordings needed;
- captions/on-screen copy;
- CTA;
- claim risks or feature dependencies.

For App Store preview videos, verify current Apple technical requirements before final export.

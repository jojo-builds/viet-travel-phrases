# Projects

Use this folder for cross-functional marketing projects.

Examples:

- App Store launch kit;
- first paid ad test;
- TikTok/Reels launch sprint;
- beta tester recruitment;
- Vietnam traveler landing page;
- screenshot and preview video production.

Each project folder should include:

- `brief.md` - goal, audience, offer, scope, constraints, and success metric;
- `assets-needed.md` - screenshots, recordings, copy, design, or research required;
- `status.md` - current state, decisions, blockers, and next actions.

Keep supporting specialist files in their natural folders when useful, then link to them from the project brief.

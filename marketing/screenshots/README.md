# Screenshots

Use this folder for App Store screenshot plans, shot lists, device frame decisions, copy overlays, and screenshot QA.

Each screenshot plan should include:

- target device sizes;
- route or launch state;
- screen purpose;
- overlay copy;
- required app state;
- capture command or manual capture notes;
- QA notes for crop, readability, and feature truth.

Final screenshots should use the native iOS app, not old Expo or web mockups.

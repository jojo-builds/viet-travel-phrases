# T-148 feature brief

## Source
- Follow-on after completed `T-147`
- Orchestrator-approved next move on `2026-04-23`

## Feature
Implement the first major visual-fidelity pass so the coded Liquid Glass answer page looks materially closer to the approved mockup direction instead of just proving structure and data flow.

## Intent
- close the visual gap between:
  - the approved target direction from the user's ChatGPT mockup
  - the current coded answer-page reality
- keep the strong AI-shaped answer workflow from `T-144` and `T-147`
- upgrade the page so it feels premium, native iOS, and visually deliberate rather than "structurally correct but still rough"

## Locked visual direction
- highly native iOS
- strong Liquid Glass control layer
- white / very light gray content base
- restrained Vietnam red and yellow accents only
- atmospheric hero image header with Ha Long Bay-style Vietnam destination identity
- floating Liquid Glass back button
- large elegant Vietnamese title
- English translation below
- pronunciation below
- large premium audio dock with:
  - favorite
  - prominent play
  - 0.5x / 0.75x / 1.0x
- answer sections below the hero should feel clean, refined, and product-like
- bottom floating toolbar should feel distinctly native and intentional

## Specific visual gaps to close
- hero image/header treatment still feels weaker than the approved mockup
- typography hierarchy needs to feel more premium and intentional
- audio dock needs to feel more like the approved central glass control bar
- lower sections need better spacing, tone, and visual hierarchy
- toolbar needs to feel more cohesive with the hero and page shell

## Product constraints from orchestrator
- preserve the current data-driven answer-page behavior from `T-147`
- do not revert back to a flat phrase-detail screen
- prioritize what is most visible to the user in the preview
- this must produce something you can open and immediately feel is closer to the locked mockup
- this is a meaningful task and must use the full 3-gate / 4-reviewer contract

# Tagalog Substantial Expansion Plan

## Target

- Add `63` new phrase families and `126` new phrase rows.
- Keep one `say-first` primary per family plus one secondary row using only:
  - `more-polite`
  - `clearer`
  - `also-common`
- Use `audio_status=planned` for every new row so the pack stays validator-safe without pretending audio exists.
- Expand relation-ready coverage from the current `16` starter-core sample to a larger packet built around the old anchors plus the new traveler-friction families.

## Batch shape

- New families: `63`
- New rows: `126`
- New starter primaries: `23`
- New premium primaries: `40`
- Secondary rows:
  - starter-primary families get premium variants
  - premium-primary families keep both rows premium

## Relation-ready approach

- Keep the old seed anchors in the relation sample where they still make sense.
- Add every new family primary to the expansion packet ledgers in:
  - `content-draft/tagalog/first-wave-priority.csv`
  - `content-draft/tagalog/tagalog-v2-first-wave.csv`
- Expand `relation-sample-v1.json` around traveler-forward paths:
  - ride pickup -> route correction -> drop-off / entrance
  - reservation -> breakfast / luggage / key card / hot water / Wi-Fi / checkout
  - menu / restrictions -> less sweet / extra rice / separate payment
  - price check -> total -> change -> receipt / card failure / large bill
  - map help -> entrance / exit / stop / mark-on-map / safe walking
  - repair -> write it down / number again / phone typing / English help / pharmacy / fever / stomach pain

## Guardrails

- No new scenario ids in this pass.
- No Liquid Glass or Viet-lane work.
- No fake ready-audio claims.
- Keep phrasing compact and travel-utility-first even when confidence notes remain honest in task logs and content notes.

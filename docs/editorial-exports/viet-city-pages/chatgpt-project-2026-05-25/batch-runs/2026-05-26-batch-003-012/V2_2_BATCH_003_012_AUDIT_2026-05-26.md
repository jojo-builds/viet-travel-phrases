## What Improved

- The best entries are now noticeably more concrete than the earlier Codex-style drafts.
- Reader View usually appears before implementation notes, which makes review possible without screenshots.
- Most batches respect the ready-audio phrase-card limit and avoid visible database phrases like `useful because`, `reference line`, `content role`, and `this page helps`.
- ChatGPT self-scores are useful as a revision loop, but still need to trigger actual visible-line revisions instead of just reporting confidence.

## Drift Found

1. Heading scaffolds started becoming a house style.
   - Repeated starters included `Let...`, `Start with...`, `Good when...`, `Still worth...`, and the body phrase `works best`.
   - These are not always wrong in isolation, but across 45 listings they begin to sound generated.

2. Phrase cards still need a stronger reusable-action rule.
   - Some outputs treated a ready place-name audio row as permission to render a visible phrase card.
   - The product risk is one-off phrase-card bloat. Place-name audio should usually support pronunciation/name handling, not the visible useful phrase-card set.

3. Source notes leaked tool artifacts.
   - A few batches included public links with `utm_source=chatgpt.com`.
   - These are not app-visible, but they clutter review and make the handoff feel less editorial.

4. The first session failure was not detected early enough.
   - `batch_003` produced only a stub after a long run.
   - Future launches need a first-line/output-shape check after seeding, so stalled sessions are retried immediately.

## Tightening Applied

Applied to the local Project source pack and the linked Source Bundle Google Doc:

- phrase cards are reusable traveler actions, not place-name recognition by default
- repeated heading scaffolds must be revised before final output
- scores below `28/30`, or database-like first screens, require one visible-line revision before final output
- final outputs should avoid public source URLs and tracking links unless explicitly requested
- blocked sessions should return `BLOCKED_STUB` instead of partial text

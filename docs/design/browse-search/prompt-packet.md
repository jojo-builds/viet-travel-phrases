# Browse/Search Prompt Packet

These prompts produced the raster mockups in `assets/`. They were guided by the live simulator chrome references captured in `docs/design/reference-shots/2026-05-01/`.

## Shared Style Constraints

- Native iOS Liquid Glass, not a responsive web page.
- Current SpeakLocal bottom admin chrome: frosted dock for Home, Browse, Saved, Practice plus separate raised Search island.
- Restrained Vietnam red/gold accents, clean white content areas, premium travel utility.
- No Melo on Browse/Search concepts.
- Realistic traveler examples, no lorem ipsum.

## Browse Default

```text
Use case: ui-mockup
Asset type: production-quality visual design mockup, single iPhone screenshot.

Browse tab selected in restrained red. No mascot.
Screen content: Title "Browse" and short helper copy "Choose a real travel situation." Lead with traveler situations first as large Liquid Glass cards: Airport, Hotel, Food, Getting Around, Shopping, Emergency, Local greetings. Include small city shortcut chips for Hanoi, Ho Chi Minh City, Da Nang, Hoi An, Hue, All Vietnam. Include a calm "Start here" shelf with Essentials and First day in Vietnam.
Composition: readable on phone, premium travel utility, not SaaS dashboard, no childish art, no busy gradients, restrained Vietnam red and warm gold accents only. Screenshot should look like a final native app screen, not a wireframe or website.
```

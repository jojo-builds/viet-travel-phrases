## Shared Scope Note

These prompts were generated during the Vietnamese iOS design pass, so several image prompts mention Vietnam colors and city bucket-list entries. The locked product direction is broader: Melo is the Speak Local chameleon who travels to different countries to learn different languages. Future country packs should reuse the same base character and swap only the country layer, colors, motifs, and map content.

Do not rename the mascot per country. Do not use Vietnamese terms as the shared mascot name or travel progress unit.

## 1. Six Style Options

```text
Create a single polished app-mascot style exploration sheet for Speak Local. Subject: chameleon mascot only, no other animals. Six distinct original chameleon mascot options arranged in a clean 3 x 2 grid on a warm off-white background, each option shown as a standalone character, no labels or text.

Overall brand context: premium native iOS travel phrasebook and language-practice app for adults. The chameleon travels across countries and changes color as the user practices. Friendly, cute, memorable, but not childish and not scary.

Visual direction: modern app mascot / Dribbble-style brand illustration language, strong silhouette, simple readable shapes, expressive eyes, clean shadows, thumbnail-readable. Avoid fuzzy plush doll, avoid toy photography, avoid realistic lizard skin, avoid wet reptile details, avoid costume, hats, flags, yellow star, XP, coins, badges, confetti, text, watermark.

Six options should differ clearly:
1. flat vector chameleon with smooth geometry and bold expression;
2. soft 2.5D app-icon chameleon with subtle depth, not plush;
3. editorial paper-cut chameleon with refined adult travel feel;
4. sticker-like expressive chameleon with bold outline and motion energy;
5. minimal line-and-shape chameleon for tiny UI surfaces;
6. country-camouflage chameleon with tasteful jade, ceramic blue, lotus red, and warm gold accents integrated into the body as progress motifs.

Keep every character original, consistent with Speak Local's calm white/jade/red native app aesthetic, and suitable to later become animated idle/correct/listening/bucket-list-updated states.
```

# Melo Bucket List Concepts Prompt Packet

Status: prompts used with Codex built-in image generation

## 1. Melo Base Sheet

```text
Create a polished app-mascot production concept sheet for Speak Local. Subject: Melo, a cute flat-brand chameleon mascot who travels country to country to learn languages. No text labels, no captions, no watermarks.

Style: modern flat vector app mascot, Dribbble-quality brand illustration, clean dark green outline, simple cel shadows, expressive friendly eyes, rounded non-scary body, curled tail. Must not look plush, fuzzy, clay, realistic, or 3D rendered. Keep the same character identity across every pose.

Layout: one clean warm off-white sheet with three rows.
Row 1: locked base views of Melo: front view, three-quarter view, side view, tiny app-icon silhouette.
Row 2: practice states: idle, listening with one small audio ripple, correct with warm smile, gentle correction with calm supportive expression, bucket list updated with small glow, hidden/rest with eyes closed. Keep phrase content absent.
Row 3: neutral base plus six shared unlock stages for a country bucket list: base neutral sage/cream, first phrases jade tint, city rhythm ceramic-blue patches, traveler confidence lotus-red accents, street-ready sign/stamp patterning, country attuned richer pattern coverage, fully unlocked vivid but tasteful country camouflage with jade, ceramic blue, lotus red, warm gold and soft glow.

Brand context: Speak Local is the brand; Speak Local Vietnam is the current app. Melo is shared across future country packs such as Japan, the Philippines, and Italy. Vietnam is only the first country color layer.

Avoid: fixed-path labels, flags, yellow star, hats, costumes, badges, coins, trophies, XP, confetti, leaderboards, realistic lizard texture, wet scales, scary reptile details, text.
```

## 2. Bucket List Map Concept

```text
Create a high-fidelity iOS design concept sheet for Speak Local Vietnam showing the Bucket List Map concept with Melo the flat-brand chameleon. Three iPhone portrait screens side by side on a warm off-white background. Use premium native iOS travel phrasebook style: white surfaces, large black editorial typography, jade accents, restrained Speak Local red audio/action icons, subtle glass bottom chrome. Text may be minimal and legible only where needed.

Screen 1: Home Practice screen with a card titled "Bucket List" and city chips for Hanoi, Hue, Hoi An, Da Nang, Saigon. Show small Melo in early Vietnam colors beside the card. Do not use fixed-path language.
Screen 2: Bucket List Map screen: stylized Vietnam map with city pins and stamp-like nodes. Some nodes complete, some in progress, some locked. Melo footprints or tiny chameleon marks show where Melo has been. It should feel like travel planning plus language progress, not a game board.
Screen 3: City bucket list detail for Hanoi: white cards for phrase practice, street names, taxi destinations, saved phrases. Show the completed Melo stamp and a progress ring. Use placeholders for phrase content; do not invent a content curriculum.

Mascot: Melo, same flat-brand chameleon, chameleon only, small and supportive. Avoid plush, realistic lizard, flags, yellow star, hats, costumes, badges, coins, trophies, XP, confetti, leaderboards, game-board energy, fixed-path labels, watermark, gibberish text.
```

## 3. Practice Quiz Melo Concept

```text
Create a high-fidelity iOS design concept sheet for Speak Local Vietnam showing Melo integrated into the Practice quiz area. Three iPhone portrait screens side by side on warm off-white. Premium native iOS phrasebook style: clean white surfaces, black editorial type, jade progress, restrained Speak Local red audio/action controls, subtle glass bottom chrome. Use minimal placeholder phrase content; content team will supply real phrases. Do not use fixed-path language.

Screen 1: Practice question. Large audio button, prompt area, answer choices as white cards, small Melo listening near the progress strip, not blocking answers. UI should feel useful and calm.
Screen 2: Correct answer feedback. Melo smiles subtly and gains a tiny color patch or Bucket List Stamp shimmer. Show source/page link and next action; no confetti, no trophy.
Screen 3: Gentle correction. Melo is supportive, small, calm, pointing to the corrected phrase card. Show a short explanation area and retry/continue action. Tone is respectful, never punitive.

Mascot: Melo flat-brand chameleon only; same silhouette and expression family as the base sheet. Chameleon should be small-to-medium and never overtake phrase content. Avoid plush, realistic lizard, flags, yellow star, hats, costumes, badges, coins, trophies, XP, confetti, leaderboards, childish game UI, watermark, gibberish text.
```

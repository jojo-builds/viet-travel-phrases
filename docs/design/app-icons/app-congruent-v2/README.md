# SpeakLocal App-Congruent Icon Family V2

This pass responds to the concern that the earlier icon exploration felt too disconnected from the actual SpeakLocal Vietnam app. Instead of treating the icon as a standalone premium travel emblem, these options compress the app experience into an icon system:

- white phrase-card surface;
- red audio/play action as the most recognizable shared mark;
- jade saved/progress cues;
- country-specific travel layer behind the shared foreground;
- Melo only as a restrained curl/progress cue when it makes the icon stronger.

## Recommendation

Launch-test **Option A: Phrase Card + Audio Button** against **Option B: Phrase Card + Melo Tail**.

Option A is the safest fit with the app because it looks like the actual product: phrase card, audio, saved/progress, and travel context. Option B is the best mascot-compatible direction because Melo becomes a small brand behavior, not a full character takeover. Option D should stay as the small-size discipline reference if either A or B gets too detailed.

Do not lead with Option C unless Browse/map/trip planning becomes the dominant App Store story. It is clear, but map pins are more generic than SpeakLocal's audio phrase utility.

## Country Family Model

The country system should keep the foreground stable and vary the background:

- **SpeakLocal base:** neutral warm-white glass, red audio, jade saved/progress.
- **Vietnam:** red/jade warmth with lotus, coastline, or Hanoi/Ha Long-style travel cues.
- **Philippines:** blue coast, sun, palms, island travel cues.
- **Italy:** deep green landscape, arches, cypress/old-city cues.
- **Germany:** charcoal/forest/rail or mountain travel cues.
- **Japan:** indigo, wave, sun, cherry blossom or mountain cues.

The point is not to make flag stickers. Each country should feel local, but the red audio card should make it immediately recognizable as SpeakLocal.

# Prompt Packet

## Shared Direction

Design square iOS app icon family concepts for SpeakLocal, a premium native iOS travel phrase app. The icons must feel connected to the real app: soft white phrase cards, a prominent red audio/play action, jade saved/progress cues, and restrained Liquid Glass depth. Show a base SpeakLocal icon plus country variants for Vietnam, Philippines, Italy, Germany, and Japan. Avoid flag stickers, text, childish mascots, and generic SaaS marks.

## Option A

Create a phrase-card plus audio-button icon family. The foreground should resemble a saved phrase card from the app, with a large red audio waveform button and a small jade saved/progress mark. Country identity appears as a subtle background motif: Vietnam lotus/coast, Philippines island/sun, Italy arches/green landscape, Germany rail/forest, Japan wave/cherry/sun.

## Option B

Create a phrase-card plus subtle Melo-tail icon family. Use a small chameleon tail curl as a jade route/progress stroke, curling inward naturally toward the belly direction, not like a wheel. Melo should not be a full character. Keep the red audio action and white phrase card dominant.

## Option C

Create an offline map-pin plus audio-phrase icon family. Combine a map pin, phrase card, red audio button, and offline saved check into one premium iOS icon. Keep the map pin useful but avoid making it look like a generic maps app.

## Option D

Create the cleanest small-size icon family. Use only a warm white phrase surface, one large red audio waveform button, jade saved/progress cue, and a minimal country route/motif layer. Prioritize recognizability at tiny Home Screen and Spotlight sizes.

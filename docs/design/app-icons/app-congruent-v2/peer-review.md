# Peer Review

## Scope

Read-only review of the app-congruent icon v2 packet for native iOS fit, brand congruence, country-family scalability, small-size clarity, and Melo risk.

## Findings

- **Native/app congruence:** Better than the previous emblem-first pass. The red audio button, white phrase card, and jade saved/progress cue connect directly to the current SpeakLocal Vietnam UI language.
- **Brand system:** The strongest reusable system is stable foreground plus variable country layer. This lets Vietnam, Philippines, Italy, Germany, and Japan feel local without each becoming a separate unrelated icon.
- **Best launch candidates:** Option A is the safest app-connected candidate. Option B is the strongest if Melo should be represented, because the mascot is reduced to a subtle tail/progress cue.
- **Small-size clarity:** Option D survives compression best and should be used as a simplification reference when finalizing A or B.
- **Mascot risk:** Avoid full Melo in the app icon for launch. A full character could pull the brand toward a game or child-learning tone, which conflicts with the restrained travel-utility direction.
- **Country motif risk:** Final art should avoid literal flags and over-specific landmarks. Use one or two country cues per variant, not a collage.

## Recommendation

Move forward with Option A and Option B as the real decision pair. If the team wants zero mascot in the icon, choose A. If the team wants the mascot to become part of the long-term SpeakLocal family, choose B and simplify the tail into a clean vector cue.

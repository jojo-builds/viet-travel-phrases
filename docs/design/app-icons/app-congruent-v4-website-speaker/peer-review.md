# Peer Review

## Scope

Read-only review of the website-speaker icon iteration for app congruence, audio-phrasebook clarity, family scalability, and small-size risk.

## Findings

- **Better match to web/legacy control:** The icon now references the `AudioPlayButton` `volume-high` direction instead of a generic waveform badge.
- **Phrasebook message improves:** The subtle treatment reads more like a playable phrase card, which is closer to the product than the red waveform circle.
- **Solid treatment risk:** The solid red treatment is more legible, but it reintroduces the dominant red block problem and can feel less premium.
- **Glyph-only risk:** The glyph-only version is clean but loses the obvious "button you tap to hear a phrase" behavior.
- **Country family remains stable:** Vietnam, Philippines, Italy, Germany, and Japan can still share the foreground system and vary only the background layer.
- **Melo handling:** B Subtle remains the best mascot-compatible direction because the tail is still a small system cue.

## Recommendation

Use **A Subtle** and **B Subtle** as the next decision pair. Keep **B Solid** only as a small-size legibility fallback. Do not return to the red waveform circle.

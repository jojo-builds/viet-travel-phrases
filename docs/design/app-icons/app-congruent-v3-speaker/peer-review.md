# Peer Review

## Scope

Read-only review of the speaker-mark icon iteration for app congruence, phrasebook clarity, family scalability, and small-size legibility.

## Findings

- **App congruence improved:** Replacing the waveform with a `speaker.wave.2.fill`-style cue aligns the icon with the native `AudioSpeakerButton` pattern used on phrase rows and practice/listing surfaces.
- **Product meaning improved:** The speaker reads more like an audio phrasebook. The previous waveform could imply recording, voice memo, podcasting, or generic sound.
- **Play button avoided:** This is better than a play triangle for the app icon because the product is not video-first and the native phrase rows already teach users to tap speaker controls.
- **Family system still works:** Vietnam, Philippines, Italy, Germany, and Japan still share the same foreground while changing only the background country motif.
- **Main tradeoff:** The app-faithful glass speaker is softer at tiny sizes. The red-disc speaker is more legible, but feels less like the current app control.
- **Melo handling:** B Glass remains the best Melo-compatible direction because the tail is a small system cue, not a full character.

## Recommendation

Use **A Glass** and **B Glass** for the next decision. Keep **B Red Alt** as a legibility fallback only. Do not return to the waveform badge.

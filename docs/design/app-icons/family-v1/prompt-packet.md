# SpeakLocal App Icon Family v2 Prompt Packet

Use these prompts to regenerate or extend the app icon packet. The source imagery was created with Codex built-in image generation, then normalized locally into 1024 px exports and review sheets.

## Global Rules

- Use case: `logo-brand`.
- Asset type: production-quality iOS app icon concept, square 1:1 image.
- No phone frame, no labels, no words, no watermark.
- Prioritize recognizable silhouettes over small details.
- Use premium iOS glass/enamel/ceramic depth.
- Avoid generic chatbot marks, translation arrows, flags as stickers, full costume mascots, and known IP.
- If Melo is used, make it an abstract premium brand mark or restrained companion cue, not a childish character takeover.

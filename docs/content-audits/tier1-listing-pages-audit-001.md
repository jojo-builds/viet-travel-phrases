## Classification Method

- `strong`: useful structure, no immediate content-only blocker, and either custom depth, variants, nearby links, or flagship handling.
- `thin`: too short for Tier 1 even after generation; needs more usage, tone, or choice teaching.
- `awkward`: phrase intent is a fragment, overloaded label, or social/small-talk expression that needs custom explanation to avoid feeling like a database row.
- `placeholder-like`: readable but still built mostly from generic generator scaffolding.
- `over-templated`: useful enough to ship after this cleanup, but still visibly formulaic and should receive hand-authored page-specific insight.
- `negative/frictional`: user-facing warning labels or caution framing. This is now zero in the generated native resource after this batch.
- `missing useful child links`: rows that should probably open canonical child pages but currently do not.

## What Changed This Batch

- Replaced generated `Watch out` sections with `Good to know` sections in authored source JSON and `native-ios/Resources/viet-authored-listing-pages.json`.
- Changed those sections from warning callout presentation to tip callout presentation.
- Rewrote negative generator guidance such as demand/phone/urgent-medical cautions into positive practical traveler notes.
- Replaced the most repeated generic context sentence with scenario-aware guidance for transport, hotels, food, shopping, phone, airport, health, bathroom, and repair moments.
- Regenerated `content-draft/viet/listing-pages/**`, `_tier-one-index.json`, `native-ios/Resources/viet-authored-listing-pages.json`, and `native-ios/Resources/viet-authored-audio-audit.json` from the generator.
